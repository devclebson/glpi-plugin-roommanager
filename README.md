# Room Manager Plugin para GLPI

Plugin de gestão de reserva de salas focado em autoatendimento (Self-Service).

## Funcionalidades Planejadas
* Visualização em Grade de Horários (Time Slots).
* Filtro por Sede/Localização (Abas).
* Interface simplificada para colaboradores.
* Integração com Inventário do GLPI.

## Requisitos
* GLPI >= 10.0.0
